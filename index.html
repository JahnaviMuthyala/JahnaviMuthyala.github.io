PR Metrics AI Agent

A conversational agent that turns GitHub activity into engineering KPIs. A manager gives a GitHub username, MAL name or repo name plus a date range, and gets a benchmark-scored table back in seconds. It runs in Microsoft Teams and M365 Copilot.

  • Computes commits, reviews, PRs raised, coding time, cycle time, PR size, PR involvement, PR maturity and review depth.
  • Auto-categorizes engineers and MALs into Elite, Good, Needs Improvement or Needs Focus so managers see productivity at a glance.
  • Built on four Power Automate tools (Get PR Metrics, List GitHub PRs, Get Repos by Token, Get Repos by MAL) and the GitHub REST API.
  • Rule-based PR filtering and parallelized batch processing keep it fast on large repos.
  • Result: manual PR-metric compilation time cut by 80%, with real-time visibility into team delivery health.
